## Elevator Pitch
The Advanced Calculus Calculator is a powerful, Python-based mathematical tool designed for students, educators, and mathematics enthusiasts. It offers symbolic differentiation, integration, and comprehensive basic mathematics operations through an intuitive command-line interface. With 200+ pre-loaded formulas, high precision calculations (28 decimal places), and an extensible architecture, it's perfect for learning, teaching, and solving complex mathematical problems. Built with clean, professional code and comprehensive documentation, it exemplifies best practices in educational software development.

## Key Features Summary
- **Derivatives**: Power rule, product rule, quotient rule, chain rule
